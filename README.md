# La Carrera Política v6 — ¿Podés llegar a Presidente?

![Banner](banner.jpg)

> ¿Podés llegar de militante de comité de Cordón a la Torre Ejecutiva sin que te coman vivo en la interna?

**[▶️ JUGAR AHORA](https://elpresidente168.github.io/elpresidente168/)**

Simulador político uruguayo. Texto, decisiones y rosca. Elecciones reales, internas sangrientas, tapas de Búsqueda y operaciones en el Palacio.

---

### ¿De qué va?

Arrancás con 0 votos, 0 pesos y un comité que se llueve. Tenés que hacer carrera: volanteada en feria, rosca en el bar, acto bajo lluvia en el interior, debate en TV y negociación a las 3 AM en el Palacio Legislativo.

No es un TEG. Es Uruguay. Cada decisión te cuesta capital político.

### ¿Qué tiene la v6?

**Elecciones reales del sistema uruguayo:**
*   Junta Departamental (Montevideo)
*   Senado 
*   Presidencia con balotaje

**La rosca:**
*   Internas partidarias donde te cagan tus propios compañeros
*   Sistema de listas y acumulación
*   Tapas de Búsqueda generadas según tus cagadas
*   Encuestas de Factum / Equipos / Cifra que te dan o te matan
*   Negociación por cargos, intendencias y ministerios
*   Eventos random bien uruguayos: desde paro del PIT-CNT hasta sequía en el campo

### Cómo se juega

1.  Elegís partido y departamento base
2.  Gestionás tres recursos: **Plata, Militancia y Prensa**
3.  Tomá decisiones morales cuestionables
4.  Llegá a Presidente o terminá de asesor en una consultora

No hay tutorial. Como en la vida real.

### Correrlo local

Este proyecto está hecho con Vite + React.

```bash
# Clonar
git clone https://github.com/elpresidente168/elpresidente168.git
cd elpresidente168

# Instalar
npm install

# Dev
npm run dev

# Build para GitHub Pages
npm run build
```
